# Hounter

Hounter is a responsive real estate website for exploring featured properties, viewing home details, reading customer reviews, and connecting with property agents.

## Features

- Property search interface
- Featured house listings
- House tour section
- Customer testimonials
- Real estate articles
- Newsletter subscription
- Contact form
- Social and partner links

## Tech Stack

- Angular
- TypeScript
- SCSS
- HTML

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

Build the project:

```bash
npm run build
```

## Project Description

A clean real estate landing page designed to help users discover and explore homes easily.
